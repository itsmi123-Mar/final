MathQuest classroom login

PUPILS
- Enter the pupil's complete registered name exactly as listed in script/data/player_data.gd (capitalization is ignored).
- Select the pupil's assigned grade.
- Enter the pupil's LRN in the password field.

The project registers 5 Grade 3 pupils and 5 Grade 4 pupils. Teacher accounts
open a grade-filtered dashboard; pupil accounts open the game. Progress is
stored locally in user://mathquest_progress.json on the device running Godot.

PRIVACY / SECURITY
LRNs are confidential learner identifiers. Restrict distribution of this
project and its embedded credentials to authorized classroom use. This is an
offline prototype, not secure production authentication. Do not publish the
project or its credentials publicly.
